🚀 Overview
Conva AI is a modern AI application designed to combine the power of Large Language Models, media processing, automation, and intelligent workflows into a single platform.
The project focuses on creating a seamless AI experience with support for:
💬 Conversational AI
🧠 LLM-powered reasoning
🎥 AI media workflows
📄 Retrieval-Augmented Generation (RAG)
🔌 API integrations
⚡ Real-time streaming responses
🛠 Modular architecture for scalability
Whether you're building AI assistants, automation systems, or media generation pipelines, Conva AI provides a flexible foundation.

⚙️ Installation
1. Clone the Repository
git clone https://github.com/redoxfusion/Conva-ai.git
cd Conva-ai
2. Install Dependencies
Frontend
cd frontend
npm install
Backend
cd backend
pip install -r requirements.txt
🔑 Environment Variables
Create a .env file in the root directory.
Example:
OPENAI_API_KEY=your_api_key
DATABASE_URL=your_database_url
NEXT_PUBLIC_API_URL=http://localhost:8000
▶️ Running the Project
Start Backend
cd backend
uvicorn main:app --reload
Start Frontend
cd frontend
npm run dev
The application will be available at:
http://localhost:3000
